# FRAME לטלפון

אפליקציה שעורכת קליפים בתוך הטלפון. בוחרים סרטון מהגלריה, לוחצים "ערכו לי", ומקבלים קליפים אנכיים עם כתוביות מונפשות בעברית, מעקב אחרי הדובר, קיצוץ שתיקות, מוזיקה ואפקטים.

**פתיחה:** https://ettett7.github.io/frame/

**התקנה למסך הבית:**
- באייפון: פותחים ב־Safari, לוחצים "שיתוף" ואז "הוספה למסך הבית".
- באנדרואיד: פותחים ב־Chrome ומאשרים "התקנה".

**פרטיות:** הכול רץ בתוך הטלפון. הסרטונים לא נשלחים לשום שרת. המודלים (תמלול וזיהוי פנים) יורדים פעם אחת, ומשם האפליקציה עובדת גם בלי אינטרנט.
